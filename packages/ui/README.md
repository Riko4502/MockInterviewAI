# @packages/ui

Дизайн-система и библиотека презентационных React-компонентов монорепозитория **MockInterviewAI**.

Пакет построен на базе headless-примитивов **Radix UI**, утилит **Tailwind CSS v4** и `@packages/utils` (`cn`, `cva`, `VariantProps`), обеспечивая высокую производительность, строгую типобезопасность и соответствие стандартам доступности (WAI-ARIA).

---

## 📦 Установка и подключение

Пакет является внутренним воркспейсом монорепозитория:

```bash
# Импорт компонентов и типов
import { Button, Card, Input, Tabs, type ButtonProps } from "@packages/ui";

# Подключение глобальных стилей и CSS-переменных темы (в корневом layout приложения)
import "@packages/ui/globals.css";
```

## 🛠️ Архитектурные правила и стандарты

1. **Импорты утилит:**
   * Утилиты стилизации `cn`, `cva`, `cx` и тип `VariantProps` импортируются из `@packages/utils`:
     ```tsx
     import { cn, cva, type VariantProps } from "@packages/utils";
     ```
2. **Импорты иконок:**
   * Все иконки импортируются исключительно из пакета `@packages/icons`:
     ```tsx
     import { SearchIcon, SettingsIcon } from "@packages/icons";
     ```
3. **Строгая типизация TypeScript:**
   * Полный запрет на использование типа `any` и операторов принудительного приведения типов `as`.
4. **Русскоязычная документация:**
   * Все JSDoc-комментарии, описания пропсов и документация к историям оформляются на русском языке.
