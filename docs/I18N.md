# Архитектура и руководство по интернационализации (@packages/i18n)

Данный документ описывает архитектуру локализации, структуру пакета `@packages/i18n`, правила именования словарей и интеграцию с приложениями монорепозитория на **Next.js App Router** (`apps/web` и `apps/landing`).

---

## 1. Архитектура и назначение пакета

Пакет `@packages/i18n` является **Single Source of Truth (единым источником правды)** для всех текстовых констант, переводов и языковых настроек платформы **MockInterviewAI**.

```
                           ┌────────────────────────┐
                           │    @packages/i18n      │
                           │  - JSON-словари        │
                           │  - TypeScript-типы     │
                           │  - Конфигурация языков │
                           └───────────┬────────────┘
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
        ┌───────────────────────┐             ┌───────────────────────┐
        │   apps/web (Next.js)  │             │ apps/landing (Next.js)│
        │  - App Router         │             │  - App Router         │
        │  - Client (i18next)   │             │  - Server Components  │
        │  - RSC (getMessages)  │             │  - RSC (getMessages)  │
        │  - Strict Type-Safety │             │  - Strict Type-Safety │
        └───────────────────────┘             └───────────────────────┘
```

### Ключевые принципы:
- **Строгая типизация (Type Safety)**: TypeScript контролирует корректность ключей переводов на этапе компиляции, предотвращая опечатки и отсутствующие переводы.
- **Поддержка Server и Client Components (Next.js App Router)**:
  - В **Server Components (RSC)** переводы читаются синхронно через функцию `getMessages(locale)` с нулевым весом бандла и без накладных расходов гидратации.
  - В **Client Components (`"use client"`)** используется хук `useTranslation` из `react-i18next` с динамическим переключением языка без перезагрузки страницы.
- **Модульность (Namespaces)**: Переводы разделены по доменным областям (неймспейсам) для удобства поддержки и организации кода.

## 2. Поддерживаемые локали

| Код | Язык | Статус | Лейбл в UI |
| :--- | :--- | :--- | :--- |
| **`ru`** | Русский | **По умолчанию (Default)** | `Русский` |
| **`en`** | English | Поддерживается | `English` |

Константы экспортируются из `@packages/i18n`:
```ts
import { defaultLocale, locales, localeLabels, type Locale } from "@packages/i18n";

console.log(defaultLocale); // 'ru'
console.log(locales);       // ['ru', 'en']
console.log(localeLabels);  // { ru: 'Русский', en: 'English' }
```

## 3. Структура пакета и пространств имён (Namespaces)

```text
packages/i18n/
├── src/
│   ├── config.ts              # Константы (список локалей, дефолтная локаль, лейблы)
│   ├── types.ts               # Типы (Messages, Locale, MessageNamespace)
│   ├── index.ts               # Точка входа (экспорт messages, getMessages, хелперов)
│   └── locales/
│       ├── ru/                # Русская локаль (эталон)
│       │   ├── common.json    # Глобальные кнопки, действия, навигация, ошибки
│       │   ├── auth.json      # Формы входа, регистрации, сброса пароля
│       │   └── interview.json # Терминология симулятора, статусы, подсказки AI
│       └── en/                # Английская локаль
│           ├── common.json
│           ├── auth.json
│           └── interview.json
├── package.json
├── tsconfig.json
└── README.md
```

### Назначение пространств имён:

1. **`common`** (`common.json`)
   - Глобальная навигация, шапка, футер, кнопки действий (`actions.save`, `actions.cancel`, `actions.submit`).
   - Системные уведомления, общие ошибки валидации и сетевые статусы.

2. **`auth`** (`auth.json`)
   - Страницы входа, регистрации, восстановления доступа.
   - Подписи к полям ввода, плейсхолдеры, валидационные сообщения форм авторизации.

3. **`interview`** (`interview.json`)
   - Компоненты комнаты собеседования: таймер, управление камерой/микрофоном.
   - Редактор кода: выбор языка программирования, статусы выполнения.
   - AI-подсказки: счетчик оставшихся подсказок, статусы генерации.
   - Фидбек и оценка: форма обратной связи, критерии оценки.

## 4. Экспорты пакета `@packages/i18n`

| Экспорт | Тип | Описание |
| :--- | :--- | :--- |
| `messages` | `Record<Locale, Messages>` | Полный объект всех ресурсов переводов для передачи в `i18next.init({ resources: messages })` |
| `locales` | `readonly ['ru', 'en']` | Список всех зарегистрированных кодов локалей |
| `defaultLocale` | `'ru'` | Дефолтный язык платформы |
| `localeLabels` | `Record<Locale, string>` | Словарь читаемых названий языков для переключателей (`LanguageSwitcher`) |
| `getMessages(locale)` | `(locale: string) => Messages` | Функция для получения словарей конкретного языка (с фоллбэком на `defaultLocale`) |
| `type Messages` | `interface` | Корневой тип словарей, используемый для типизации `CustomTypeOptions` в `i18next` |
| `type Locale` | `'ru' \| 'en'` | Union-тип доступных локалей |
| `type MessageNamespace` | `'common' \| 'auth' \| 'interview'` | Union-тип зарегистрированных пространств имён |

## 5. Руководство по интеграции в Next.js (App Router)

### 5.1. Настройка приложения (`apps/web` и `apps/landing`)

#### 1. Подключение зависимостей в `package.json`
```json
{
  "dependencies": {
    "@packages/i18n": "workspace:*",
    "i18next": "^24.0.0",
    "react-i18next": "^15.0.0"
  }
}
```

#### 2. Транспиляция пакета в `next.config.ts`
```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  transpilePackages: ["@packages/i18n", "@packages/ui", "@packages/icons"],
};

export default nextConfig;
```

#### 3. Настройка автодополнения и строгой типизации TypeScript (`src/types/i18next.d.ts`)
```ts
import type { Messages } from "@packages/i18n";

declare module "i18next" {
  interface CustomTypeOptions {
    defaultNS: "common";
    resources: Messages;
  }
}
```

### 5.2. Использование в React Server Components (RSC)

В серверных компонентах Next.js (страницы, layout, статические секции лендинга) не требуется рантайм `i18next`. Достаточно вызывать `getMessages(locale)`:

```tsx
// app/page.tsx (Server Component)
import { getMessages, defaultLocale, type Locale } from "@packages/i18n";

interface PageProps {
  params?: Promise<{ lang?: Locale }>;
}

export default async function HomePage({ params }: PageProps) {
  const resolvedParams = params ? await params : undefined;
  const lang = resolvedParams?.lang ?? defaultLocale;
  const dict = getMessages(lang);

  return (
    <main className="container mx-auto py-12">
      <h1 className="text-4xl font-bold">{dict.common.appName}</h1>
      <p className="text-muted-foreground mt-2">{dict.interview.heroSubtitle}</p>
      
      <div className="mt-6 flex gap-4">
        <a href="/login" className="btn-primary">
          {dict.common.navigation.login}
        </a>
      </div>
    </main>
  );
}
```

**Преимущества для RSC:**
- ⚡ **Zero Bundle Size**: клиент не загружает парсер `i18next`.
- 🚀 **Быстрый SSR/SSG**: словари внедряются прямо в готовый HTML.

### 5.3. Использование в Client Components (`"use client"`)

Для интерактивных клиентских компонентов (формы, модальные окна, переключатели языков) используется `i18next` + `react-i18next`.

#### Инициализация i18next (`src/shared/lib/i18n/index.ts`):
```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import { defaultLocale, locales, messages } from "@packages/i18n";

if (!i18n.isInitialized) {
  i18n.use(initReactI18next).init({
    resources: messages,
    lng: defaultLocale,
    fallbackLng: defaultLocale,
    supportedLngs: locales,
    defaultNS: "common",
    ns: ["common", "auth", "interview"],
    interpolation: {
      escapeValue: false, // React защищает от XSS
    },
  });
}

export default i18n;
```

#### Пример клиентского компонента:
```tsx
"use client";

import { useTranslation } from "react-i18next";
import { localeLabels, locales, type Locale } from "@packages/i18n";
import "@/shared/lib/i18n";

export function HeaderLanguageSwitcher() {
  const { t, i18n } = useTranslation(["common", "auth"]);
  const currentLocale = (i18n.language as Locale) || "ru";

  const toggleLanguage = (locale: Locale) => {
    i18n.changeLanguage(locale);
  };

  return (
    <header className="flex items-center justify-between p-4 border-b">
      <span className="font-semibold">{t("common:appName")}</span>

      <div className="flex gap-2">
        {locales.map((loc) => (
          <button
            key={loc}
            onClick={() => toggleLanguage(loc)}
            className={`px-3 py-1 text-sm rounded ${
              currentLocale === loc ? "bg-primary text-white" : "hover:bg-muted"
            }`}
          >
            {localeLabels[loc]}
          </button>
        ))}
      </div>
    </header>
  );
}
```

## 6. Правила и соглашения по добавлению переводов

### 6.1. Соглашение по именованию ключей:
- Используйте **camelCase** для ключей (`submitButton`, `forgotPasswordTitle`).
- Используйте вложенные объекты для группировки логически связанных элементов:
  ```json
  {
    "login": {
      "title": "Вход в аккаунт",
      "emailLabel": "Электронная почта",
      "submitButton": "Войти"
    }
  }
  ```
- Не создавайте плоские ключи с точками в названии (используйте вложенные JSON-объекты).

### 6.2. Порядок добавления нового перевода:
1. Откройте соответствующий файл в эталонной локали: `packages/i18n/src/locales/ru/<namespace>.json`.
2. Добавьте новый ключ и русский текст.
3. Откройте файл английской локали: `packages/i18n/src/locales/en/<namespace>.json` и добавьте перевод для того же ключа.
4. Благодаря экспорту интерфейсов в `packages/i18n/src/types.ts` типы TypeScript обновятся автоматически.

### 6.3. Добавление нового языка:
1. Зарегистрируйте новый код локали в [packages/i18n/src/config.ts](file:///d:/проекты/MockInterviewAI/packages/i18n/src/config.ts):
   ```ts
   export const locales = ['ru', 'en', 'es'] as const;
   export const localeLabels: Record<Locale, string> = {
     ru: 'Русский',
     en: 'English',
     es: 'Español',
   };
   ```
2. Создайте каталог `packages/i18n/src/locales/es/` с соответствующими `common.json`, `auth.json`, `interview.json`.
3. Импортируйте и добавьте их в объект словарей в [packages/i18n/src/index.ts](file:///d:/проекты/MockInterviewAI/packages/i18n/src/index.ts).
