# Тестирование (Testing Guidelines)

---

## 1. Пирамида и инструменты тестирования

| Уровень | Инструмент | Что тестируем | Расположение файлов |
|---|---|---|---|
| **Unit** | `Vitest` | Чистые функции, утилиты, мапперы данных, кастомные хуки | Рядом с файлом: `format-date.test.ts` |
| **Component / Integration** | `Vitest` + `React Testing Library` | Кнопки, поля ввода, формы, виджеты | `LoginForm.test.tsx` рядом с компонентом |
| **E2E** | `Playwright` | Критические сценарии (Логин → Создание комнаты → Интервью) | В директории `e2e/` |

---

## 2. Именование и организация файлов тестов

* Файлы тестов именуются с суффиксом `.test.ts` (или `.test.tsx`) и располагаются **в той же папке**, что и тестируемый модуль:
  ```text
  features/auth/
  ├── ui/
  │   ├── LoginForm.tsx
  │   └── LoginForm.test.tsx
  └── model/
      ├── auth-mapper.ts
      └── auth-mapper.test.ts
  ```

---

## 3. Команды запуска тестов

```bash
# Запуск всех тестов в монорепозитории
pnpm test

# Запуск тестов конкретного приложения (apps/web)
pnpm test:web

# Запуск тестов в режиме отслеживания (watch mode)
pnpm --filter web vitest
```

---

## 4. Что обязательно покрывать тестами?

1. Все утилитарные функции в `shared/lib`.
2. Мапперы данных между DTO и UI-моделями в `entities/*/model/mappers.ts`.
3. Логику валидации нестандартных схем Zod.
4. Ключевые пользовательские сценарии форм (успешная отправка, отображение ошибок).
