# Управление зависимостями (Dependencies)

---

## 1. Правила добавления новых зависимостей

Перед добавлением любого нового npm-пакета проверьте:
1. **Есть ли уже аналог в проекте?** (например, не добавляйте `axios`, если используется `fetch`/`@packages/api`; не добавляйте `dayjs`, если достаточно нативных методов `Intl`).
2. **Влияние на размер бандла:** проверьте размер пакета через [Bundlephobia](https://bundlephobia.com).
3. **Поддержка:** активен ли репозиторий библиотеки, нет ли известных уязвимостей.

---

## 2. Команды установки

```bash
# Установка зависимости в конкретное приложение
pnpm --filter web add <package-name>

# Установка dev-зависимости в UI Kit
pnpm --filter @packages/ui add -D <package-name>

# Установка общей зависимости в корень монорепозитория
pnpm add -w -D <package-name>
```
