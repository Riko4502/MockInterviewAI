## Фронтенд-специфичный чек-лист

При работе над фронтендом (`apps/web`, `apps/landing`, `@packages/ui`):

- [ ] Все тесты проходят локально (`pnpm --filter web test` или `pnpm test`).
- [ ] Линтер не выдает ошибок (`pnpm --filter web lint`).
- [ ] Проект успешно собирается (`pnpm --filter web build`).
- [ ] Для новых или изменённых UI-компонентов добавлены/обновлены истории в **Storybook** (`@packages/ui` / `apps/ui-docs`).
- [ ] Соблюдены правила архитектуры **Feature-Sliced Design (FSD)** (слои, слайсы, публичные API `index.ts`).
- [ ] Приложены скриншоты или GIF-анимации в описании PR при любых визуальных изменениях интерфейса.
