# Интернационализация (i18n)

Документация по работе с пакетом локализации `@packages/i18n` в монорепозитории **MockInterviewAI**.

---

## Обзор архитектуры

Пакет `@packages/i18n` служит **единым источником правды** для словарей переводов, поддерживаемых локалей и TypeScript-типов. Формат словарей оптимизирован для прямой интеграции с **`i18next` / `react-i18next`** в `apps/web` (Next.js) и стандартного использования в `apps/landing` (Next.js).

---

## Поддерживаемые локали

* **`ru`** — Русский (дефолтная локаль)
* **`en`** — English

---

## Структура словарей

Словари разбиты по пространствам имён (**namespaces**), которые напрямую соответствуют неймспейсам в `i18next`:

* **`common.json`** (`common`) — кнопки, действия, глобальная навигация;
* **`auth.json`** (`auth`) — формы логина/регистрации, плейсхолдеры, ошибки валидации;
* **`interview.json`** (`interview`) — терминология симулятора интервью, статусы сессий, фидбек.

```text
packages/i18n/
├── src/
│   ├── config.ts              # Константы (locales, defaultLocale, localeLabels)
│   ├── types.ts               # Типы (Messages, Locale, MessageNamespace)
│   ├── index.ts               # Экспорт словарей (messages, getMessages)
│   └── locales/
│       ├── ru/
│       │   ├── common.json
│       │   ├── auth.json
│       │   └── interview.json
│       └── en/
│           ├── common.json
│           ├── auth.json
│           └── interview.json
├── package.json
├── tsconfig.json
└── README.md
```

## Экспорты пакета

| Экспорт | Тип | Описание |
|---|---|---|
| `messages` | `Record<Locale, Messages>` | **Готовый объект `resources` для `i18next.init({ resources: messages })`** |
| `locales` | `readonly ['ru', 'en']` | Массив поддерживаемых языков |
| `defaultLocale` | `'ru'` | Дефолтная локаль приложения |
| `localeLabels` | `Record<Locale, string>` | Названия языков (`'Русский'`, `'English'`) |
| `getMessages(locale)` | `(locale: string) => Messages` | Хелпер получения словарей для конкретного языка |
| `type Messages` | `interface` | Тип ресурсов для расширения `CustomTypeOptions` в `i18next` |
| `type Locale` | `'ru' \| 'en'` | Union-тип поддерживаемых локалей |
| `type MessageNamespace` | `'common' \| 'auth' \| 'interview'` | Union-тип доступных неймспейсов |

## Подключение в `apps/web` (Next.js + i18next)

### Шаг 1: Установка зависимостей в `apps/web`
```bash
pnpm --filter web add i18next react-i18next
```

В `apps/web/package.json` добавьте пакет словарей:
```json
{
  "dependencies": {
    "@packages/i18n": "workspace:*",
    "i18next": "^24.0.0",
    "react-i18next": "^15.0.0"
  }
}
```

### Шаг 2: Включение транспиляции пакета
В `apps/web/next.config.ts` (или `next.config.mjs`):
```ts
const nextConfig = {
  transpilePackages: ["@packages/i18n", "@packages/ui", "@packages/icons"],
};

export default nextConfig;
```

### Шаг 3: Инициализация `i18next`
Создайте файл `apps/web/src/lib/i18n.ts`:
```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import { defaultLocale, locales, messages } from "@packages/i18n";

i18n.use(initReactI18next).init({
  resources: messages, // Передаем словари напрямую из @packages/i18n
  lng: defaultLocale,
  fallbackLng: defaultLocale,
  supportedLngs: locales,
  defaultNS: "common",
  ns: ["common", "auth", "interview"],
  interpolation: {
    escapeValue: false, // React уже защищает от XSS
  },
});

export default i18n;
```

### Шаг 4: Настройка строгой типизации для `useTranslation` (TypeScript)
Создайте `apps/web/src/types/i18next.d.ts`, чтобы получить **автодополнение ключей** в `t(...)`:
```ts
import type { Messages } from "@packages/i18n";

declare module "i18next" {
  interface CustomTypeOptions {
    defaultNS: "common";
    resources: Messages;
  }
}
```

### Шаг 5: Использование в компонентах

```tsx
"use client";

import { useTranslation } from "react-i18next";
import "@/lib/i18n"; // Инициализация i18next

export function LoginForm() {
  // Подключаем нужный namespace
  const { t, i18n } = useTranslation("auth");
  const { t: tCommon } = useTranslation("common");

  return (
    <div>
      <h2>{t("login.title")}</h2>
      <p>{t("login.description")}</p>

      {/* Переключение языка */}
      <button onClick={() => i18n.changeLanguage(i18n.language === "ru" ? "en" : "ru")}>
        {i18n.language === "ru" ? "English" : "Русский"}
      </button>

      <button type="submit">
        {tCommon("actions.submit")}
      </button>
    </div>
  );
}
```

## Использование в Server Components (Next.js App Router: `apps/web` и `apps/landing`)

В серверных компонентах Next.js (RSC) словари можно использовать напрямую через функцию `getMessages(locale)` без рантайма `i18next`:

```tsx
// app/page.tsx (Server Component)
import { getMessages, defaultLocale, type Locale } from "@packages/i18n";

interface PageProps {
  params?: Promise<{ lang?: Locale }>;
}

export default async function Page({ params }: PageProps) {
  const resolvedParams = params ? await params : undefined;
  const lang = resolvedParams?.lang ?? defaultLocale;
  const dict = getMessages(lang);

  return (
    <header>
      <h1>{dict.common.appName}</h1>
      <nav>
        <a href="/login">{dict.common.navigation.login}</a>
        <a href="/register">{dict.common.navigation.register}</a>
      </nav>
    </header>
  );
}
```

## Как добавить новый перевод или язык

1. **Добавление нового ключа**:
   * Добавьте ключ в файл `src/locales/ru/<namespace>.json`.
   * Добавьте перевод этого же ключа в `src/locales/en/<namespace>.json`.
   * Тип `Messages` обновится автоматически, и `useTranslation` сразу предложит новый ключ.

2. **Добавление нового языка** (например, `es`):
   * Добавьте `'es'` в массив `locales` в `src/config.ts`.
   * Создайте файлы `src/locales/es/*.json`.
   * Подключите импорты в `src/index.ts`.
