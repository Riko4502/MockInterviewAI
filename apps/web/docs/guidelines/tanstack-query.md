# TanStack Query

## Назначение

TanStack Query используется в **MockInterviewAI** для работы с **server
state**:

-   API-запросы;
-   кеширование данных;
-   синхронизация данных клиента с сервером;
-   состояния загрузки и ошибок;
-   повторное получение и инвалидирование данных.

------------------------------------------------------------------------

## Основное правило

``` text
API / server state
        ↓
TanStack Query
```

Данные, источником истины для которых является backend, не должны
дублироваться в Zustand.

------------------------------------------------------------------------

## Когда использовать

-   получение данных API;
-   mutations;
-   кеширование;
-   invalidation после изменений;
-   loading/error состояния серверных операций.

------------------------------------------------------------------------

## Когда НЕ использовать

Не использовать TanStack Query для чисто локального UI-состояния:

-   открыта ли модалка;
-   выбранная локальная вкладка;
-   временное UI-состояние без backend;
-   состояние интерфейса, которое не является server state.

Для такого состояния при необходимости используется Zustand или
локальный React state.

------------------------------------------------------------------------

## Ограничения и правила

-   Не копировать query data в Zustand без отдельной архитектурной
    причины.
-   Query keys должны быть предсказуемыми и централизованными в рамках
    соответствующего домена.
-   После mutation обновлять или инвалидировать связанные query.
-   Компоненты не должны самостоятельно реализовывать собственный кеш
    поверх TanStack Query.
