# Zustand

## Назначение

Zustand используется в **MockInterviewAI** для глобального **client/UI
state**, которому необходимо совместное использование между несколькими
частями интерфейса.

------------------------------------------------------------------------

## Основное правило

``` text
UI / client state
        ↓
Zustand
```

Server state остаётся ответственностью TanStack Query.

------------------------------------------------------------------------

## Когда использовать

-   состояние, которое требуется нескольким удалённым компонентам;
-   глобальное UI-состояние;
-   client state, который неудобно передавать через props.

------------------------------------------------------------------------

## Когда НЕ использовать

Не создавать store, если достаточно:

-   локального `useState`;
-   состояния формы React Hook Form;
-   query cache TanStack Query.

Не помещать в Zustand данные API только ради глобального доступа к ним.

------------------------------------------------------------------------

## Ограничения и правила

-   Store должен иметь конкретную ответственность.
-   Не создавать один глобальный store для всего приложения.
-   Не смешивать независимые домены в одном store.
-   Не дублировать server state.
-   Сначала выбирать минимально необходимый уровень состояния.
