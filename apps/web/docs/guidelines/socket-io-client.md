# Socket.IO Client

## Назначение

`socket.io-client` используется в **MockInterviewAI** для
realtime-взаимодействия frontend с соответствующим realtime-сервисом.

------------------------------------------------------------------------

## Принцип использования

Realtime-соединение рассматривается как инфраструктура приложения.

Создание соединения, его lifecycle и базовая конфигурация должны быть
централизованы.

------------------------------------------------------------------------

## Когда использовать

-   realtime-события;
-   получение серверных обновлений без polling;
-   сценарии, которым действительно требуется постоянное соединение.

------------------------------------------------------------------------

## Когда НЕ использовать

Не использовать Socket.IO:

-   вместо обычного HTTP API для стандартных CRUD-запросов;
-   для данных, которым не требуется realtime;
-   если задачу корректно решает TanStack Query.

------------------------------------------------------------------------

## Ограничения и правила

-   Не создавать новое socket-соединение в каждом feature-компоненте.
-   Не дублировать listeners без необходимости.
-   Обязательно учитывать cleanup подписок.
-   Бизнес-компоненты не должны знать детали создания транспортного
    соединения.
-   Server state, полученный обычным API, остаётся ответственностью
    TanStack Query.
