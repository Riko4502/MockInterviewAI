# Biome

## Назначение

Biome является единым инструментом linting и formatting frontend
**MockInterviewAI**.

Он используется вместо параллельной связки ESLint + Prettier.

------------------------------------------------------------------------

## Конфигурация

``` text
apps/web/biome.json
```

------------------------------------------------------------------------

## Ответственность

Biome выполняет:

-   lint;
-   formatting;
-   поддерживаемые code checks;
-   разрешённые auto-fix.

------------------------------------------------------------------------

## Использование в проекте

Полная frontend-проверка запускается через workspace script:

``` bash
pnpm --filter web lint
```

Форматирование:

``` bash
pnpm --filter web format
```

На pre-commit Biome запускается через цепочку:

``` text
Husky
  ↓
lint-staged
  ↓
Biome
```

------------------------------------------------------------------------

## Ограничения и правила

-   Не добавлять ESLint/Prettier параллельно без отдельного
    архитектурного решения.
-   Pre-commit проверяет staged-файлы.
-   Полная проверка проекта выполняется отдельно и должна выполняться в
    CI.
-   CI не должен автоматически исправлять присланный код.
