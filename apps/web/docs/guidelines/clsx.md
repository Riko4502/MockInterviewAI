# clsx

## Назначение

`clsx` используется в **MockInterviewAI** для формирования `className`,
когда набор Tailwind CSS-классов зависит от props или состояния.

------------------------------------------------------------------------

## Принцип использования

Используем `clsx` для динамических классов:

``` tsx
className={clsx(
    'flex',
    directionClasses[direction],
    justifyClasses[justify],
    gap && gapClasses[gap],
    max && 'w-full',
    className,
)}
```

Для статических классов `clsx` не требуется:

``` tsx
<div className="flex items-center gap-4" />
```

------------------------------------------------------------------------

## Когда использовать

-   условные Tailwind-классы;
-   варианты UI-компонента;
-   объединение внутренних классов с внешним `className`;
-   классы, зависящие от props или состояния.

------------------------------------------------------------------------

## Когда НЕ использовать

``` tsx
// ❌ избыточно
<div className={clsx('flex', 'items-center', 'gap-4')} />

// ✅
<div className="flex items-center gap-4" />
```

------------------------------------------------------------------------

## Пример в проекте

`Stack` использует `clsx` для формирования layout-классов:

``` text
shared/ui/Stack
```

Для ограниченных вариантов используем типизированные mapping-объекты:

``` tsx
const directionClasses: Record<StackDirection, string> = {
    row: 'flex-row',
    column: 'flex-col',
};
```

------------------------------------------------------------------------

## Ограничения и правила

-   Не использовать ручную конкатенацию строк для сложных условных
    `className`.
-   Не использовать `clsx`, если все классы статичны.
-   Не переносить в `clsx` бизнес-логику.
-   Ограниченные варианты компонента описывать типами и
    mapping-объектами.
