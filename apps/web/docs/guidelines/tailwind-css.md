# Tailwind CSS

## Назначение

Tailwind CSS является основным способом стилизации frontend
**MockInterviewAI**.

------------------------------------------------------------------------

## Принцип использования

Стили компонента описываются utility-классами Tailwind:

``` tsx
<div className="flex items-center gap-4" />
```

Для динамического набора классов используется `clsx`.

------------------------------------------------------------------------

## Когда использовать

Tailwind используется для:

-   layout;
-   spacing;
-   typography;
-   responsive styles;
-   визуальных состояний;
-   стилизации общих UI-компонентов.

------------------------------------------------------------------------

## CSS-файлы

Не создавать CSS/SCSS Module для компонента, если задача полностью
решается Tailwind.

Глобальные стили и действительно глобальные правила остаются на уровне
соответствующей глобальной stylesheet-конфигурации приложения.

------------------------------------------------------------------------

## Ограничения и правила

-   Не смешивать Tailwind и CSS Modules без необходимости.
-   Не создавать собственный CSS только ради замены существующего
    Tailwind utility.
-   Повторяющийся UI-паттерн выносить в компонент, а не копировать
    длинные наборы классов по всему проекту.
-   Для динамических классов использовать проектный guideline `clsx.md`.
