# shadcn/ui

## Назначение

`shadcn/ui` используется в **MockInterviewAI** как основа UI Kit.

Компоненты должны интегрироваться с архитектурой проекта и общим
UI-слоем.

------------------------------------------------------------------------

## Расположение

Переиспользуемые UI-компоненты проекта располагаются в:

``` text
src/shared/ui/
```

Компоненты не должны хаотично размещаться внутри `features`.

------------------------------------------------------------------------

## Принцип использования

shadcn/ui рассматривается как источник UI-примитивов, которые становятся
частью кодовой базы проекта.

Перед добавлением нового компонента необходимо проверить, нет ли уже
подходящего компонента в `shared/ui`.

------------------------------------------------------------------------

## Когда использовать

-   базовые переиспользуемые UI-примитивы;
-   элементы интерфейса, для которых shadcn/ui даёт подходящую основу;
-   компоненты, которые затем используются несколькими частями
    приложения.

------------------------------------------------------------------------

## Ограничения и правила

-   Соблюдать FSD при размещении компонентов.
-   Не переносить бизнес-логику в `shared/ui`.
-   Не создавать дубликаты уже существующих UI-компонентов.
-   Изменения общих UI-примитивов учитывать как изменения, потенциально
    влияющие на несколько features.
-   Стилизация проекта строится на Tailwind CSS.
