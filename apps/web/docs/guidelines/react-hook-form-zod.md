# React Hook Form + Zod

## Назначение

В **MockInterviewAI**:

-   `react-hook-form` отвечает за управление состоянием формы;
-   `zod` отвечает за схемы и runtime validation;
-   `@hookform/resolvers` связывает React Hook Form и Zod.

------------------------------------------------------------------------

## Принцип использования

``` text
Form state
    ↓
React Hook Form

Validation schema
    ↓
Zod

Integration
    ↓
@hookform/resolvers
```

------------------------------------------------------------------------

## Когда использовать

Связка используется для пользовательских форм, где необходимы:

-   ввод данных;
-   validation;
-   сообщения об ошибках;
-   submit;
-   типизированная схема данных.

------------------------------------------------------------------------

## Валидация

Ошибки валидации должны отображаться рядом с соответствующим полем или в
контексте формы.

Не использовать глобальные уведомления как основной способ отображения
field validation.

------------------------------------------------------------------------

## Ограничения и правила

-   Не дублировать одну и ту же validation-логику вручную в компоненте и
    в Zod schema.
-   Схема должна отражать контракт данных формы.
-   UI-компонент поля не должен содержать бизнес-правила конкретной
    формы.
-   Состояние формы не переносится в Zustand без отдельной
    необходимости.
