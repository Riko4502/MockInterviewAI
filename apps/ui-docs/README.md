# UI Docs & Storybook

Витрина компонентов дизайн-системы ([`@packages/ui`](../../packages/ui)) и галерея иконок ([`@packages/icons`](../../packages/icons)) проекта **MockInterviewAI**.

## 🚀 Команды

```bash
# Запуск Storybook dev-сервера (http://localhost:6006)
pnpm dev
# или из корня репозитория:
pnpm dev:storybook

# Сборка статического Storybook
pnpm build
# или из корня репозитория:
pnpm build:storybook

# Проверка типов
pnpm typecheck
```

Подробные правила и стандарты создания Stories описаны в файле [docs/frontend/ui/storybook.md](../../docs/frontend/ui/storybook.md).
